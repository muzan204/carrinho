# 🛒 Carrinho — React + Redux

<p align="center">
  Projeto de Carrinho de Compras desenvolvido com React e Redux 🚀
</p>

---

# 📦 Instalação do Projeto

## 🚀 1️⃣ Criando a Aplicação React

Crie o projeto:

```bash
npx create-react-app carrinho
```

---

## 📂 2️⃣ Entrando na Pasta

Acesse a pasta do projeto:

```bash
cd carrinho
```

---

## 📦 3️⃣ Instalando Redux

Instale as dependências necessárias:

```bash
npm install redux react-redux
```

---

# ▶️ Executando o Projeto

## 🚀 4️⃣ Iniciando o Servidor

Execute:

```bash
npm start
```

---

## 🌐 5️⃣ Abrindo no Navegador

Abra no navegador:

```txt
http://localhost:3000
```

---
